**Qual a implicação prática para um serviço de retina terciário?**

Para um serviço terciário, a implicação prática é a necessidade de uma gestão estruturada em três pilares: **tecnologia de ponta** (acesso a OCT/OCTA), **capacitação técnica** (injetores treinados) e, fundamentalmente, **eficiência logística**. O serviço deve garantir um fluxo de atendimento ágil para o retratamento, uma vez que atrasos nas injeções podem resultar em perda de resposta terapêutica e piora do prognóstico visual do paciente.
